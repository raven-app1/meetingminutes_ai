Antigravity Subscription သို့မဟုတ် Gemini Web အသုံးပြုနည်း (API Key မလိုပါ)

သင့်တွင် Antigravity subscription သို့မဟုတ် Gemini Advanced စာရင်းသွင်းမှု ရှိပြီး Gemini API Key မသုံးလိုပါက အောက်ပါ လွယ်ကူသော နည်းလမ်း ၂ မျိုးဖြင့် အသုံးပြုနိုင်ပါသည်:

နည်းလမ်း ၁ - Gemini Web စနစ် (အလွယ်ကူဆုံး - Browser တွင် ချက်ချင်းသုံးနိုင်သည်)

  • ၁။ ဤ Web App တွင် အစည်းအဝေး ခေါင်းစဉ်နှင့် လိုချင်သော မှတ်တမ်းပုံစံ (အကျဉ်းချုပ်၊ အသေးစိတ်၊ တာဝန်များ စသည်) ကို ရွေးချယ်ပါ။
  • ၂။ အောက်ပါ 'မြန်မာ အစည်းအဝေး Prompt ကူးယူမည်' ခလုတ်ကို နှိပ်ပါ။
  • ၃။ Gemini Web (gemini.google.com) ကို ဖွင့်ပြီး သင့် အသံဖိုင်ကို ဆွဲထည့် (Upload) လိုက်ပါ။
  • ၄။ ကူးယူထားသော Prompt ကို Paste လုပ်ပြီး Enter နှိပ်ပါ။ (Gemini Advanced / Antigravity က မြန်မာအသံဖိုင်ကို တိုက်ရိုက် နားထောင်ပေးပါသည်)
  • ၅။ Gemini မှ ထွက်လာသော စာသားကို ဤနေရာတွင် ပြန်လည် Paste လုပ်ပေးလိုက်ပါက သပ်ရပ်လှပသော စာရွက်စာတမ်းပုံစံ၊ Word ဖိုင်နှင့် PDF အဖြစ် ချက်ချင်း ပြောင်းလဲပေးမည် ဖြစ်ပါသည်။
🚀 Gemini Web ဖွင့်မည် ↗
💡 Netlify Cloud ပုံစံ (Zero Local Dependency): သင်သည် ဤ app ကို Netlify / Cloud ပေါ်တွင် အသုံးပြုနေပါသည်။ နည်းလမ်း ၁ (Gemini Web) သို့မဟုတ် Free Google AI Studio API Key ဖြင့် ကွန်ပျူတာပေါ်တွင် မည်သည့် script/server မှ run စရာမလိုဘဲ ၁၀၀% အပြည့်အဝ အသုံးပြုနိုင်ပါသည်။

နည်းလမ်း ၂ - Local Antigravity CLI Bridge (စက်တွင်း အလိုအလျောက်ချိတ်ဆက်မှု)

(Local Development အတွက်သာ)

သင့်ကွန်ပျူတာတွင် `agy` CLI ထည့်သွင်းထားပြီး Antigravity subscription ရှိပါက နောက်ခံ Bridge runner ကို ဖွင့်ထားရုံဖြင့် ဤ Web App မှ CLI ကို တိုက်ရိုက်ခေါ်ယူပြီး မှတ်တမ်း ထုတ်ယူနိုင်ပါသည်:

python3 bridge.py
Bridge ချိတ်ဆက်မှု အခြေအနေ: စစ်ဆေးနေပါသည်...

သိမ်းဆည်းထားသော အစည်းအဝေး မှတ်တမ်းများ

ယခုအချိန်အထိ သိမ်းဆည်းထားသော အစည်းအဝေးမှတ်တမ်း မရှိသေးပါ။

ချိန်ညှိချက်များ (Settings)

အခမဲ့ API Key ကို Google AI Studio တွင် ရယူနိုင်ပါသည်။ Key သည် သင့် Browser ၏ LocalStorage တွင်သာ လုံခြုံစွာ သိမ်းဆည်းပါသည်။

အသုံးပြုပုံ လမ်းညွှန်နှင့် မကြာခဏ မေးလေ့ရှိသော မေးခွန်းများ

၁။ Backend ဆာဗာ မရှိဘဲ ဘယ်လို အလုပ်လုပ်တာလဲ?

ဤ Web App သည် သင့် Browser အတွင်း၌သာ ၁၀၀% အလုပ်လုပ်ပါသည်။ သင့်အသံဖိုင်များနှင့် မှတ်တမ်းများသည် သင့်ကွန်ပျူတာမှ အခြားဆာဗာများသို့ မရောက်ရှိဘဲ လုံခြုံစိတ်ချရပါသည်။ Google AI Studio ကို သုံးလျှင်လည်း Browser မှ Google API သို့ တိုက်ရိုက် လုံခြုံစွာ ဆက်သွယ်ပါသည်။

၂။ မြန်မာစကား အသံဖိုင်များကို AI က ကောင်းစွာ နားလည်ပါသလား?

Gemini 2.5 Flash / 1.5 Flash သည် မြန်မာဘာသာ အသံဖိုင်များကို တိုက်ရိုက် နားထောင်နိုင်စွမ်း ရှိပါသည်။ အစည်းအဝေးများတွင် သုံးလေ့ရှိသော မြန်မာ+English ရောနှောစကားများ (Code-switching) နှင့် ရုံးသုံး ဝေါဟာရများကို သဘာဝကျကျ အစည်းအဝေးမှတ်တမ်းအဖြစ် ပြောင်းလဲပေးနိုင်ရန် စနစ်တကျ Prompt များ ချိန်ညှိထားပါသည်။

၃။ အသံဖိုင် အရွယ်အစား ကြီးမားနေပါက ဘာလုပ်ရမလဲ?

မိနစ် ၆၀ အထက် အသံဖိုင်ကြီးများအတွက် နည်းလမ်း ၁ (Gemini Web သို့ တိုက်ရိုက် တင်ခြင်း) ကို အကြံပြုပါသည်။ Gemini Web သည် ဖိုင်ကြီးများကို အခမဲ့ အကန့်အသတ်မရှိ လက်ခံပြီး ဤ App မှ ထုတ်ပေးသော Prompt နှင့် ပေါင်းစပ်ပါက အကောင်းဆုံး ရလဒ် ရရှိပါမည်။
